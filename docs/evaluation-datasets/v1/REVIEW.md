## 抽查一：G002，智能手表报告黄金题

**题目**：总结2026年第二季度全球腕戴设备、智能手表和手环出货情况，解释三者口径及变化方向。

**来源**：[IDC官方文章](https://www.idc.com/resource-center/blog/2026年二季度全球腕戴设备市场同比下滑4-3，增长压力/)，2026-09-09发布。打开后看最前面的市场数据段。

| 核对项 | 本包参考 |
| --- | --- |
| 全球腕戴设备 | 4801万台，同比下降4.3% |
| 其中智能手表 | 3708万台，同比下降4.2% |
| 其中手环 | 1092万台，同比下降4.7% |
| 统计范围 | 全球，2026Q2，出货量；不是中国零售额 |

只要报告正确表达这些事实并有来源，表达方式不同可以合格。4801与分项和相差1万，不能把公开四舍五入数字强行修成精确相等。

**不能通过的例子**：把4801万写成“中国智能手表销量”；说腕戴增长4.3%；引用存在但不支持相应数字。

## 抽查二：R009，主模型故障后固定备用

**题目**：主模型首次调用连接失败，备用成功；重开数据库并清空进程内健康状态，主模型此时已恢复，再调用原任务。

**预期**：主模型总共调用1次，备用共2次；任务备用绑定持久化；两个后续逻辑调用保留独立用量，第一次主失败和备用成功属于同一logical_call_id。

**你检查什么**：是否符合“当前任务一旦切备用就一直用备用，主恢复只影响后续新任务”的产品要求。

依据：[已有回归测试](../../../backend/tests/test_model_failover.py)中的test_switch_stays_on_backup_after_recovery_and_reopen，以及[主备恢复SDD](../../module-sdd/RELIABILITY-01.md)。不是编造的新切换政策。

本题只验收接管/持久化机制，不宣称真实备用接口已联网可用，也不直接证明最终报告质量合格。

机器记录：[regression.json](private/regression.json)中的R009；场景：[fixtures.json](fixtures.json)中的R009。人工状态仍为pending。
