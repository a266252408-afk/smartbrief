# v3 专用离线协议 v3-offline-1

本协议仅用于程序行为验收，pipeline_version固定为3。旧synthetic-protocol-1继续固定v1，其成绩不作为本协议成绩；未增加产品API或下拉选项。

offline-1.json：30例挑战（10合格、10错误、10边界），15题完整任务（10充分、5无来源）。5个主题为农业灌溉、轨道交通、工业泵、太阳能组件、图书出版；前3个开发分区，后2个保留分区。每主题两条合格题是原句/块重排与等价摘要标题的配对例，不是10种完全独立主题。全部为人工合成材料，不是实际市场数据。来源原句、标注理由和分区均在输入内，原始字节哈希见manifest.json。supplement-1.json为本轮绑定缺口修复后新增的港口设备、纺织机械保留材料，原输入不改答案。

执行：在backend使用项目.venv Python运行tests/test_v3_offline_protocol.py；完整任务从planner开始，真实scheduler/Writer/Reviewer/LangGraph/SQLite，模型与网络边界才使用脚本替身。验收检查最终权威文档渲染、证据、质量与历史落库；零来源任务应失败并无报告，失败是该边界的正确行为。empty/finish_reason=length最多两次不能补造正文。

挑战的事实/结构/引用正确性经真实构建与校验判断；不能将外部模型的passed自报当正确答案。v3审核只读权威文档，污染派生Markdown不会覆盖文档；篡改文档的数值/年份会拒绝。对象变化与否定翻转只在明确单指标模板/去否定后原句逐字相同的范围内验证，一般语义仍需要可靠语义审核；没有声称任意同义改写或对象都能由规则证明。

双向变形：块重排/摘要同义标题保留事实集合；年份/数量/对象/引用/极性变化拒绝。历史原始/检查点夹具保持R00清单哈希；历史不完整原始响应仍不冒充完整回放。更广矩阵（补丁、相依修改、全稿、预算、旧库、恢复、v1/v2/API）通过同版本完整后端套件验收，见R06最终凭据，不将局部76项当作全部矩阵。

离线重复替身没有抽样意义。第6.3节90次审核、45次生成、主模型逐调用身份、至少5个实际检索主题与人工逐项核验仍全部pending_authorization，留R07单独获批；本协议通过不等于主模型在线质量或服务已加载新代码。

## 试运行与回退

默认新任务pipeline仍为2；后续获批试运行仅对新任务请求显式report_pipeline_version=3。保留原有档位/额度/有限重试及故障回退配置，不临时升档，备用路径成功单列。当前不重启服务、不迁移真实库。首次真实迁移先执行一致性备份与隔离恢复。

出现v3问题，停止创建新v3任务，新任务显式2；已有v3保留或暂停，使用认识schema5和v3的兼容代码恢复，不用旧版本强行读取。代码回退不等于数据恢复，遵守docs/runbooks/git-and-data-rollback.md。现有报告质量与模型原文/证据快照不重写。实际启用与线上身份记录由R07单独执行。
