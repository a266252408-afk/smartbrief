# 面试展示增强版 PRD

状态：已生成施工基线，业务尚未开工。目标版本 0.2.0。

## 用户与主流程

单所有者使用系统管理资料并生成研究报告；面试展示者解释引用、质量、成本和异常恢复；只读访问者仅查看允许共享的已生成结果。不同实例数据隔离，当前不做账号注册或多租户。

管理员配置服务 → 上传参考文档 → 选择资料并提交主题 → 排队/研究/写作/审核 → 展示质量状态与可回溯引用 → 导出报告；异常可查看失败原因、取消或恢复。质量通过且证据校验合格后才自动记忆。

只读用户看到的证据片段按报告共享规则脱敏；资料原件不因报告可读而自动开放。Token 不进入 URL，不持久化到浏览器 localStorage；默认会话内存保存，刷新重新输入。公网演示还需 HTTPS 反代配置，不自动部署。

## 需求与验收追踪

FR-01 环境可复现（T01）；FR-02 权限/文件/执行边界（T02）；FR-03 执行/质量分离（T03）；FR-04 引用（T04）；FR-05 文档 RAG（T05）；FR-06 可信记忆（T06）；FR-07 用量预算（T07）；FR-08 取消恢复（T08）；FR-09 评测（T09）；FR-10 持久化恢复（T10）；FR-11 展示（T11）；FR-12 性能（T12）；FR-13 总验收（T13）。每个 FR 的 AC 以对应 SDD 的 AC-Txx-1～4 为唯一验收编号。

## 非功能约束

- 默认单服务单 worker、最大并发计划为 2；不承诺分布式执行或跨进程锁。
- 默认任务 Token 预算规划为 20000；价格由用户填入，未配置不估价；在线调用和费用仍需授权。
- 整体覆盖率 >=80%，新增关键治理模块 >=95%；所有必需测试通过才提交 verified 快照。
- 新知识没有证据时不编造；自动引用检查不代表事实已被权威验证。
- T12 首屏初始 JS 传输体积相对 T11 减少至少 30%，按相同机器和测量条件比较。
- 来源、输入、日志、费用和评测可追溯，但默认不记录用户文档全文或完整提示内容。

## 非目标与未获授权事项

不做微服务、企业 SSO、多租户、分布式队列、复杂监控平台。在线效果实验、远程仓库与公网部署未获授权；它们的未完成状态必须与离线软件功能验收分开报告。
