# 面试展示增强版 PRD

状态：T01～T13已形成验证快照，0.2.0完成本地范围最终验收。Docker与在线效果依用户决定/授权延后，真实门禁见施工状态与凭据。

## 用户与主流程

单所有者使用系统管理资料并生成研究报告；面试展示者解释引用、质量、成本和异常恢复；只读访问者可以读取本实例的查询资源。不同实例数据隔离，当前不做账号注册、多租户或逐报告分享权限。

管理员配置服务 → 上传参考文档 → 选择资料并提交主题 → 排队/研究/写作/审核 → 展示质量状态与可回溯引用 → 导出报告；异常可查看失败原因、取消或恢复。质量通过且证据校验合格后才自动记忆。

## 非功能约束

- 默认单服务单 worker、任务并发为 2；同业务库使用实例文件锁拒绝第二worker，不承诺分布式执行。
- 默认任务 Token 预算为 500000；价格由用户填入，未配置不估价；在线调用和费用仍需授权，预算估算不能宣称严格金额封顶。
- 整体覆盖率 >=80%，新增关键治理模块 >=95%；所有必需测试通过才提交 verified 快照。
- 新知识没有证据时不编造；自动引用检查不代表事实已被权威验证。
- T12 首屏初始 JS 传输体积相对 T11 减少至少 30%，按相同机器和测量条件比较。
- 来源、输入、日志、费用和评测可追溯，但默认不记录用户文档全文或完整提示内容。

## 非目标与未获授权事项

不做微服务、企业 SSO、多租户、分布式队列、复杂监控平台。在线效果实验、远程仓库与公网部署未获授权；它们的未完成状态必须与离线软件功能验收分开报告。
