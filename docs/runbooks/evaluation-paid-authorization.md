# 评测真实调用的单次授权

默认不运行付费模型或真实搜索。当前页面启动的是供应商替身完整图，真实模型入口是`POST /api/v2/evaluation-center/runs`的`full_task_live`，只支持固定资料G017～G020和primary组。真实搜索仍拒绝，不能用模型授权代替搜索授权。

实际执行前由用户另行批准：案例与资料哈希、公开题干和资料片段的数据去向、模型/HTTPS端点、调用上限、每次输入UTF-8字节/输出Token上限、单价/币种、估计费用上限、有效期。后台管理员令牌只表示操作权限，不表示消费授权。

服务端通过环境`SMARTBRIEF_EVALUATION_GRANT`配置符合公共契约`EvaluationGrant`的JSON；本轮不设置。其`authorization_id`必须与请求相同，`case_ids`必须精确匹配顺序，`dataset_hash`以当前题库接口为准，`model/base_url`须同时匹配当前服务端`OPENAI_MODEL/OPENAI_BASE_URL`，密钥来自环境，不写授权JSON。到期时间必须带时区。

调用数为每案例上限；预留估计费用为案例数×最大调用数×（最大输入字节数×输入单价＋最大输出Token×输出单价）/百万。输入字节数用于保守预算，不能把它写成供应商精确分词或账单硬封顶；供应商附加计费仍需人工核对。调用前检查输入（含工具定义）与次数，输出上限传SDK，SDK重试和重定向关闭；失败尝试也占次数。

授权在启动子进程前排他写入运行目录`evaluation-center/authorizations/`，已预留的ID重启后仍不能复用。启动或归档失败也不自动退款/复用；核对真实账单后需新的明确授权和新ID。不得删除预留记录来绕过费用限制。

每个案例使用独立工作目录、任务库与检查点；搜索为冻结资料、RAG/长期记忆关闭，不加载真实.env。对外仅传本次公开题干/资料及被测模型生成上下文。归档含公开授权参数，不含密钥。真实运行、独立评分和评分器校准的成本分别管理；本阶段没有启用付费评分模型。

备份时按停写runbook保存整个`evaluation-center`，包括runs、reviews、authorizations；已有业务数据库备份不会自动覆盖这些JSON。代码回滚不恢复消费额度，也不删除失败尝试。
