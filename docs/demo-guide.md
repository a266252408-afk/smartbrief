# SmartBrief 三条演示流程

更新：2026-10-21（Asia/Shanghai）。适用版本：0.1.0 施工候选；演示样例由 T11 显式导入。

## 先说明边界

- 演示样例是仓库内固定数据，任务元数据带 `demo=true`、样例版本和生成版本；页面显示「演示数据」标识。它们**不代表在线模型效果、真实用户数据或质量评测成绩**。
- 导入演示不会启动工作流、不会调用模型、不会产生 `queued/running` 演示任务。演示任务的取消、恢复、重新生成在服务端返回 `409 DEMO_NOT_EXECUTABLE`，前端也不显示这些入口。
- 未配置模型 Key 时，演示流程仍可完整查看；此时在线生成不可用，页面会显示离线提示。
- 演示数据可随时从报告中心/任务列表删除；删除后可在首页重新导入。导入不会覆盖同任务号的用户数据，冲突时整批回滚并提示。

## 启动

后端（`backend/`，使用项目虚拟环境）：

```powershell
..\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8002
```

前端（`frontend/`）：

```powershell
npm run dev -- --host 127.0.0.1 --port 5174
```

打开 `http://127.0.0.1:5174`，使用环境变量中的管理员令牌或只读令牌认证。只有管理员可以导入演示样例；只读角色可以查看已导入样例。

## 流程一：正常报告

1. 首页「演示流程」卡片显示运行环境状态。未配置 `OPENAI_API_KEY` 时显示离线提示；未配置 `EMBEDDING_API_KEY` 时另提示上传文档检索不可用。
2. 管理员点击「导入全部演示」（或某条样例的「导入此样例」）。成功提示会明确说明不会启动生成。
3. 在「正常报告」样例点击「查看演示」，进入报告展示页。
4. 核对：质量标签为「审核通过」、页面有「演示数据」标识、正文引用 `[S1]` 可跳转到来源卡片、来源卡片保留原始 URL 与证据片段。
5. 点击「导出 Word」或「导出 PDF」。导出内容包含报告正文、来源与证据片段、质量状态、生成版本（`demo-1.0`）和演示数据类型说明。PDF 由浏览器渲染，导出失败会显示错误提示。

## 流程二：上传文档溯源

1. 导入「文档溯源」样例并点击「查看演示」。
2. 报告页「上传文档检索」卡片显示「已找到可用片段」、所选文档数量、页码、片段 ID 与相似度。
3. 点击正文引用 `[S1]`，页面跳转到对应来源卡片；卡片保留 `document_id`、`chunk_id`、页码与证据片段。
4. 导出 Word 后，文件仍包含文档 ID、片段 ID 与引用映射。

演示样例中的文档 ID 与片段 ID 是固定演示值，不对应真实上传目录；真实上传、索引与删除回归见 T05 测试。

## 流程三：服务中断恢复

1. 导入「服务异常恢复」样例并点击「查看演示」。
2. 任务详情显示「已暂停」、失败原因和已完成步骤；页面明确说明这是服务中断演示数据。
3. 真实任务在服务或配置修复后，可从任务控制区点击「恢复任务」；系统会检查快照并选择断点续跑或从头重试。
4. 演示样例不显示「恢复任务」「取消任务」「重新生成」，避免从演示页触发真实模型调用。后端同时拒绝这些动作。

## 状态与导出字段

- `execution_status`：任务是否执行完成、暂停、失败或取消。
- `quality_status`：报告质量是否通过、未通过、审核不可用或未知；与执行状态独立。
- `metadata.demo`：是否为显式演示样例；`metadata.demo_sample_id` / `demo_sample_version` 标识样例来源。
- `metadata.generator_version`：真实任务记录应用版本（当前 `0.1.0`）；演示任务记录 `demo-<样例版本>`。旧任务没有记录时显示「未记录」，不伪造版本。
- 用量未知时 Token 与费用显示「未知」，不补零。
