# 评测说明

## 默认运行范围

`backend/evaluation/runner.py` 默认只执行一个冒烟用例：便携式储能电源 2026 北美市场。其用途是验证任务执行、进度落库、指标采集和报告展示链路，不足以代表跨行业稳定性或事实准确性。

扩展用例时向 TEST_CASES 添加 topic 和 keywords；接口与测试从 case_count() 动态获取数量。执行会消耗模型与嵌入接口调用。

## 指标

| 指标 | 口径 |
| --- | --- |
| 质量通过率（success_rate） | execution_success=true且quality_passed=true、非强制输出的用例数 / 全部用例数 |
| 执行完成率 | execution_status=completed的用例数 / 全部用例数 |
| 平均耗时 | 仅执行完成用例的耗时均值（包括质量未通过） |
| P95 耗时 | 执行完成用例耗时的 P95 |
| ReAct 行动次数 | Action 日志条数 |
| 关键词覆盖率 | 预期关键词对报告全文的子串匹配，忽略大小写 |
| 记忆命中率 | 存在长期记忆命中的任务占比 |

指标目标在 metrics.py 的 TARGETS 中定义，属于期望阈值，不是已获得的成绩。雷达图将耗时与行动次数转换为达标分数。新记录metric_version=2，success是质量通过的兼容别名；强制输出、拒绝、审核不可用及unknown均不计质量成功。旧评测不回填，界面明确显示旧版执行成功口径，关键词覆盖率不能替代来源核验。
